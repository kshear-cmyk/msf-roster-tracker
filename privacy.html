Privacy Policy

Last updated: April 26, 2026

This application ("Personal Roster") is a personal tool used solely by its developer to retrieve their own game account data via the official MSF API and store it locally for personal use.

Data Collection

The application accesses only the developer's own account data, including profile information, roster, and inventory, retrieved through authenticated API calls. No data is collected from any other user.

Data Storage

All data is stored locally on the developer's personal computer. No data is transmitted to, stored on, or shared with any third-party server or service. Data is refreshed on demand and is not retained beyond 30 days, in compliance with the MSF API Terms of Use.

Data Sharing

No data is sold, licensed, shared, or otherwise disclosed to any third party. The application does not integrate with any advertising network or analytics service.

Deletion

All locally stored data can be deleted at any time by removing the local files. Upon any request from the data subject (the developer) or from Scopely, all retrieved data will be deleted immediately.

Contact

For questions regarding this policy, contact the developer through the GitHub repository at github.com/kshear-cmyk/msf-roster-tracker.
